# CreditLens

CreditLens is an AI-powered financial intelligence platform focused on
credit analysis, lending workflows, and risk assessment.

The project is being developed incrementally, starting from a simple
finance chatbot and evolving into a tool-using, RAG-enabled,
multi-agent system.

## Current Stage

### Stage 1 — CreditLens v0

A simple command-line finance assistant built with Python.

The purpose of this stage is to establish the software foundation before
introducing machine learning, LLMs, RAG, and multi-agent architecture.

## Initial Goals

- Understand Python application structure
- Handle user input
- Implement basic financial logic
- Separate application logic from financial calculations
- Introduce testing
- Establish clean project structure
